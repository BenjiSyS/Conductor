| `crates/conductor-cli/**` (headless CLI) | Claude agent |

## Integration contract

- Claude-owned crates are **leaf libraries**: they do not depend on
  `conductor-core`, so changes in core never break them and vice versa.
- Core / desktop integrate them by adding a dependency and calling their public
  API. Each crate's `lib.rs` documents its entry points.
- Before wiring a Claude crate into core/desktop, leave a note below so the
  owner can review the call site.
