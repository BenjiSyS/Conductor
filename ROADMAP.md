# Roadmap

Planned work, in order:

1. Verify the native desktop shell, onboarding, project opening, persistence and provider connections.
2. Complete end-to-end Chat, Plan, Agent and Goal execution; verify fallback, handoff, budgets, permissions and completion gates.
3. Complete MCP, extensions, verified Caveman packaging, environment repair and UI integration.
4. Complete GitHub, remote sync, browser, computer use, previews and tunnels through real runtime tests.
5. Complete signed application/catalog/integration updates, rollback and release packaging.
6. Run platform, low-resource, accessibility, performance, crash-recovery and security acceptance audits.

Each stage is done only when the real user workflow is tested end to end; unit tests alone do not count.
